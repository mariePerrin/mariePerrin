Definitions

Dataset

  • It is structured in rows and columns, with one row per observation (e.g., person) and one column per variable (e.g., age, gender, height, weight)
  • Datasets can be stored on a computer in various formats – a format for a specific program (e.g., Excel, R, SAS) or a structured Text file

File format and type

  • A delimiter is the text that separates data values in a file (a “comma delimited” file = data values separated by spaces)
  • Delimited: each variable is separated by the same character
  • A file in fixed-width format has data values that start in specific locations
  • Fixed width: each variable takes up the same number of spaces
  • A Text file (.txt, .csv = comma delimited) with any kind of delimiter (including comma) or fixed-width format

Required file structure for a statistical software

  • One row per observation: longitudinal data (>1 row per person, but only 1 row/time/person)
  • One column per variable
  • Some consistent way of knowing when one variable ends and the next begins (fixed-width or delimited)
  • If there are parts of the datafile with metadata (e.g., descriptions of the data, a codebook) or data summaries (e.g., column means), save a copy of the file with these removed before importing the data into R

Importing a file from another format (RStudio)

  • While R is a programming language, RStudio does have some menu options
  • Best practice is to import using code, not point-and-click => record what has been done
  • Using “Import Dataset” is also a great way to explore the data before importing, to see if there are problems (e.g., a column with a mix of character and numeric data)

Base R - Delimited .txt file - From Text (base)

DO: File – Import Dataset – From Text (base)

  • Browse to where the file RheumArth.txt is saved. Select that file
  • In the import dialog box:
  • Name: name the dataset (default = name of the file)
  • Encoding: change the Encoding (i.e., if the file is in a different language)
  • Heading: set = Yes (if the variable names are in the first row)
  • Row names: specify if there are row names (default = Automatic)
  • Separator: specify the delimiter (separator)

DO: Select some other delimiter options

  • See how the preview changes. Reset the delimiter to “Tab” before proceeding
  • Decimal: specify the character for decimals
  • Quote: specify if double, single, or no quotes
  • Comment: specify if there is a character that designates a line as being a comment => skipped
  • na.strings: specify which character designates missing data
  • Strings as factors: how R handles a column with characters
    • If left unchecked: a column with ANY characters will be read in as a character variable
    • If checked: a column with ANY characters will be read in as a factor variable
    • If unsure: leave unchecked then convert variables that should be factors later in the code. It is easier to fix misspellings before converting to a factor

Import Options

  • Name: name the dataset (default = name of the file)
  • Skip (skip): how many rows to skip at the top of the file
  • First Row as Names (col_names): check if the variable names are in the first row (better TRUE)
  • Trim Spaces (trim_ws): check to trim off white space at the beginning and end of values (better TRUE)
  • Open Data Viewer: check to run View() after importing to view the data in a data tab (better TRUE)
  • Delimiter (delim): specify the delimiter to use (if none, it will automatically guess)
  • Quotes (quote): default
  • Locale (locale): opens a dialog where to specify various formats (date, time, marks, encoding)
  • Escape (escape_backslash, escape_double): a character that tells R to read in the next character literally, not as a special character
  • Comment (comment): specify if there is a character that designates a line as being a comment => skipped (better default)
  • NA (na): specify what character designates missing data
  • This procedure does NOT convert character data to factors!

DO: Import RheumArth.txt with the name “RheumArth_tibble”, use Tab as the delimiter, and leave the other options at their default values

When to use file.choose()

  • Instead of specifying a file path and name in one of the read functions, there is an option to include file.choose()
  • When the code is run, one is prompted to browse to a file and select it
  • This method is not recommended as it is not reproducible
  • It returns no record of which file was actually chosen
  • However, by creating an interactive application, file.choose() is needed to allow the user to select their file

  • Females may be diagnosed earlier (e.g., due to more frequent symptoms or healthcare visits), so their Yrs_From_Dx is higher by the time of data collection
  • Males may be diagnosed later, conversely
  • Alternatively, there may be more females with long-standing disease in the dataset
